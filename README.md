# slide-creator

技術記事やマークダウンの原稿から、登壇用の HTML のスライドを作るツールです。Astro でビルドし、ブラウザで開いて発表します。

## できること

- 16:9 の枠のスライドを、横長の画面では 1 枚ずつ、縦長の画面では縦に並べて表示する
- スピーカーノートを、発表の画面の下か、別のウィンドウの発表者ビューに出す
- 発表者ビューに、今のスライド、前と次のスライド、ノート、経過時間を出す
- ライトとダークを切り替える
- すべてのスライドを紙や PDF に印刷する

見た目の決まり（色、文字、余白、レイアウト）は [DESIGN.md](DESIGN.md) にあります。

記事からスライドの原稿を作るときは、Claude Code の `/create-slide` を使います（下の「記事から原稿を作る」）。

## 準備

Node.js 24 と pnpm を使います。パッケージマネージャーは pnpm だけで、`npm` は使いません。

```bash
pnpm install
```

## 見本のデッキを開く

```bash
pnpm dev
```

表示された URL を開くと、デッキの一覧が出ます。見本のデッキは 2 本あります。

- `/sample/`: このツールの紹介
- `/demo/`: 記事から作ったデッキの例

## 発表の操作

ブラウザの窓を横長にすると、発表の表示になります。マウスを動かすと、スライドの右上に操作のボタンが出ます。ボタンの上にポインターを置くと、名前とキーが出ます。

| キー | 操作 |
| --- | --- |
| `→`、`PageDown`、`Space` | 次のスライドへ |
| `←`、`PageUp`、`Shift` + `Space` | 前のスライドへ |
| `Home`、`End` | 最初、最後のスライドへ |
| `N` | ノートを出す、隠す |
| `F` | 全画面にする、戻す |
| `P` | 発表者ビューを開く |
| `D` | ダークにする、ライトに戻す |

画面をクリックしても移動できます。左の 3 分の 1 で前へ、それより右で次へ進みます。タッチの画面では、横のスワイプでも移動できます。

URL の末尾の `#3` は、今のスライドの番号です。番号を付けた URL を開くと、そのスライドから始まります。

### ノート

`N` を押すと、画面の下の 3 割にノートが出ます。ノートが長いときは、ノートをクリックするか Tab でフォーカスを移してから、上下の矢印キーや `PageDown` でスクロールします。

### 発表者ビュー

`P` を押すと、発表者ビューが別のウィンドウで開きます。発表の画面をプロジェクターに、発表者ビューを手元の画面に置きます。どちらのウィンドウで移動しても、両方のスライドがそろって動きます。

発表者ビューの上の端に、経過時間のタイマーがあります。開いたときは 00:00 で止まっています。

- 再生: 数え始める。一時停止の後は続きから数える
- 一時停止: 今の値のまま止める
- 停止: 0 に戻して止める

### 印刷

ブラウザの印刷を使うと、どの表示からでも、すべてのスライドが 1 ページに 1 枚ずつ出ます。配色は、ダークにしていてもライトで出ます。

## 記事から原稿を作る

Claude Code で、記事の URL か、`.md` か `.mdx` のファイルのパスを渡します。

```
/create-slide https://example.com/article/ --minutes 20
```

- 記事を `slides/<名前>/` に全文で取り込み、素材を書き出してから、構成案を出して止まります。構成案を承認すると、原稿（`deck.mdx`）を書き、ビルドと検査、レビューまで進みます
- `--minutes` は発表の時間です。省くと、構成案の前に聞かれます
- `--yes` を付けると、構成案で止まらずに書き進めます

記事を取り込むだけなら、`pnpm ingest <URL かパス>` でも実行できます。

## デッキの書き方

デッキは、`slides/<名前>/deck.mdx` に MDX で書きます。見本の `slides/demo/deck.mdx` を写して始めると早いです。`<名前>` がページの URL（`/<名前>/`）と、ビルドした HTML の名前（`dist/<名前>.html`）になります。

- frontmatter の `title` にデッキの題名を書き、1 枚ずつ `<Slide>` を並べる。ページ番号と枚数は、ビルドのときに数えて足されるので書かない
- 題名は `slot="title"`、ノートは `slot="notes"` の要素に書く。ノートの `<p slot="notes">` は 1 行で書く
- 表紙や章の扉などは `layout` で選ぶ。使えるレイアウトと、1 枚に入れてよい量は、DESIGN.md の「レイアウト」にある

書き方の細かい決まりは、AGENTS.md の「スライドの原稿の書き方」にあります。

## 検査

| コマンド | 内容 |
| --- | --- |
| `pnpm test` | 型、リンター（Oxlint、Stylelint、markuplint）、整形、`scripts/` の単体のテスト。プッシュの前に自動で動く |
| `pnpm build` | `dist/` にビルドし、デッキごとに、書体や CSS を埋め込んだ 1 つの HTML（`dist/<名前>.html`）を作る。配るのはこのファイル |
| `pnpm test:html` | ビルドした HTML を検査する（先に `pnpm build`） |
| `pnpm test:e2e` | Chromium、Firefox、WebKit で動きと見た目を試す（先に `pnpm build`） |
| `pnpm verify` | 上の 4 つを順に実行する。PR の前に使う |

`pnpm test:e2e` を初めて動かすときは、先にブラウザを入れます。

```bash
pnpm exec playwright install
```
