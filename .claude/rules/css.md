# CSS

CSS のガイドライン（RECSSガイドライン）に従う。ルールは MCP サーバー recss-guideline で引ける。CSS は css-change のスキルの手順で書き、変えたら `pnpm lint` で Stylelint を通す。

この文書は、テーマの CSS を書く前の最小の内容である。レイヤーの構成、命名、単位の決まりは、テーマを作る作業で足す。

## 値の正本

色、文字の大きさ、余白、角丸、動きの値は `DESIGN.md` が正本で、CSS のトークンはそれを写す。`DESIGN.md` にない値を CSS に書かない。値が要るときは、先に `DESIGN.md` を変える。

## 配るものに書かないもの

CSS はスライドの HTML に埋め込まれて配られる。CSS のコメントに、ガイドラインの名前とリンクを書かない。根拠を残したいときは、ルールID だけを書く。

## 本書と違う点

ガイドラインのルールと違う作りを、理由と一緒にここに記録する。
